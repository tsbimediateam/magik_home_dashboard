# Magik Home – Lead Dashboard

Single-page dashboard (`index.html`) for the LeadSquared CRM export.

- Open the page and click **Load CSV…** to load an export; the file is read in the browser only.
- If `data/leads.csv` exists next to the page, it loads automatically.

Columns used: Contact First/Last Name, Email ID, Phone Number, Contact Source, Source Campaign,
Source Medium, Source Content, Contact Stage, Created On, Property City,
Reason for Not able to Connect, Reason for Dead Lead.
